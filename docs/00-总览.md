# 《创世》完整方案 · 总览

> 一款「一句话创世」的神格 AIRP 网页游戏：玩家输入一段话，AI 生成完整世界观（可容纳、融合、魔改任意现有 IP），玩家扮演其中一位神，与一整个「活着的」神谱共处一个会自行运转的世界。

---

## 1. 游戏名候选

| 候选 | 气质 | 备注 |
|---|---|---|
| **创世**（默认） | 直白、有分量 | 与目录名、导出书名《创世史》天然呼应 |
| 万神纪 | 群像感、史诗感 | 强调「诸神共史」而非玩家独尊 |
| 遂古 | 出自《天问》「遂古之初，谁传道之」 | 古卷气质最贴，稍冷僻 |
| 神座 | 权力感 | 强调神格与位阶 |
| 执笔创世 | 点出「玩家即共同作者」 | 稍长 |

方案文档中一律以《创世》指代，定名后全局替换即可。

## 2. 一句话定位

**给中文 RP 玩家的「神格视角 AI 叙事引擎」**：SillyTavern 的自由度与世界书生态 + 后台自行运转的诸神议程 + 一部随游玩自动生长的世界百科，包装在「书写一部创世史书」的羊皮古卷体验里。

## 3. 核心支柱（Pillars）

1. **一句话创世**：任意 IP / 融合 IP / 原创魔改 → 一键生成完整世界卡组 → 卡片级重掷与手改 → 开局。
2. **活着的神谱**：6–9 位主神各有人格、声纹、议程与关系；每章结算跑「诸神回合」独立行动，行动**润物细无声**地织入叙事，玩家以占卜洞察主动揭开。
3. **生长的百科**：势力/人物/种族/地理/圣物/教团六类实体各有专属面板，自动抽取生长、栏目级迷雾、实体专属编年史——它同时就是三层记忆的可见形态。
4. **史书质感**：羊皮古卷 UI、连续书页叙事、仪式化的创世/翻章/陨落演出、整局可导出为《创世史》成书。

## 4. 决策总账（Decision Ledger）

### 定位与架构
- 自用/小圈子起步，预留公开运营扩展点；内容不设限
- TypeScript 全栈（Next.js 单体应用）；本机先行，预留 VPS Docker 部署
- BYOK：玩家自带 API Key + Base URL（OpenAI 兼容 / Anthropic / Gemini / 中转站），后端加密存储并代理转发
- 双模型槽位：**叙事模型** + **幕后模型**（诸神回合/抽取/压缩），幕后未配置则回落叙事模型
- 账号暂不做（单用户模式），全部数据表预留 `user_id`，后续接 Discord OAuth 零迁移

### 世界生成
- 一句话输入 → 一键生成完整世界卡组 → 卡片区单独重掷/手改 → 开局仪式演出
- 设定来源：模型内部知识 + 导入 SillyTavern 世界书（**双向兼容**：可导入亦可导出 ST 格式）
- 多 IP 融合时额外产出「**融合公理卡**」：体系缝合方式、力量对标、冲突仲裁，玩家可改，后续叙事与诸神回合恒引用
- 神谱默认 **6–9 主神**（人格卡+声纹卡+议程+后台回合）+ **无限次要神**（一句话设定，可升格）；原 IP 神系庞大时自动主次筛选
- 玩家神出身由 AI 从输入推断（新神/既有神/转生神/篡位者均可），卡片阶段可改
- 叙事风格卡：生成时推断，可改，可随时切换预设（史诗/网文爽文/黑深残/轻小说/仿原 IP 文风）

### 核心玩法
- 自由 RP，**纯角色内**扮演（不做 OOC 造物主面板）
- **显式尺度切换器**三档：场景/年代/纪元，文体随之切换；支持化身入世（凡人视角 RP）
- 章节：手动翻章为主 + AI 建议翻章；章末结算 = 诸神回合 + 状态抽取 + 编年史压缩 + 史官小结；等待做成**仪式化岁月流转**演出
- 诸神行动「**润物细无声**」：不打标记、不进面板，征兆织入叙事正文；玩家以占卜/洞察/审问主动查探才揭示；未揭示行动对玩家完全不可见，揭开后补录编年史
- 神神互动四通道全开：神议会直接对话（逐神注入声纹卡防串味）、凡间代理人博弈、密约写入双方议程、诸神主动事件（托梦/使者/神迹挑衅）
- **神选者系统**（不限量）：赐印记入册，独立状态卡永不压缩，追踪生老病死与信仰历程
- 可**陨落**（该时间线以史诗终章收束）+「**余烬视角**」低谷玩法（凭最后的信仰余火东山再起）+ 时间线分叉重开
- AI 行动建议：轻悬浮淡金小字、与叙事**同次生成**（不额外调用）、设置可全局关闭；除此之外不做其他输入辅助，首屏保持纯净

### 记忆与数据
- 三层记忆：**结构化状态卡**（=百科条目）+ **编年史大事记** + **检索注入**（实体名/别名/关键词索引为主，embedding 为可选增强）
- 轻状态面板：神力位阶/领域/关系标签/信仰范围，无硬数值运算
- 多存档；存档**手动导出/导入** JSON；章末自动快照仅服务于时间线分叉（非备份承诺）
- 消息四件套（全套古卷化命名）：重掷多候选=「**异文**」、编辑任意消息=「**朱批**」、章内回溯删除=「**裁去**」、续写/导演提示=「**续笔**」
- 世界模板广场（M3）：发布世界卡组为模板，他人一键开局

### 世界百科（Codex）
- 六大实体类型，各有专属面板模板：**势力**（含信仰栏）/ **人物**（含寿数、信仰历程、声纹）/ **种族** / **地理志** / **圣物·力量体系** / **教团**（独立成类）
- 正文中已入册实体名自动成**微光链接**，悬停一句话快览，点击开面板
- 条目生长：开局首批 → 每章结算抽取器自动建卡/增补 → 玩家手改优先级最高
- **栏目级迷雾**：未知栏目呈「传闻：…」或经卷残缺样式，随占卜/接触/剧情逐栏点亮
- 每个实体面板底部有**专属编年史**（人物面板=她的一生）
- **热度分层**控膨胀：活跃实体全卡；沉寂实体降为摘要卡、再出场自动复活；神选者/玩家标星永不降档
- 视觉锚点：程序化蜡封印章/墨线纹章（名字哈希生成）+ 玩家可上传图片覆盖 + 预留二期 AI 生图字段

### UI（详见 05）
- 羊皮古卷主题；日卷 + 烛光双模式；霞鹜文楷正文 + 思源宋体标题
- 桌面优先、手机可用；中央限宽连续书页正文，玩家神谕以金色引文块嵌入
- 右缘符文列 → 五页签抽屉（手绘天文图星图 / 编年史年表 / 本尊神格 / 世界设定集 / 众生百科）+ 香炉（设置）
- 朴素输入框 + 书签丝带尺度切换器；发送按钮就叫「发送」
- 动效原则：仪式浓（创世/翻章/陨落）、日常淡；更新提示用烫金微焕
- 古卷语言重译：迷雾=「此处经卷残缺」、翻章=书页翻动+章题晕开、徽记=蜡封印章

### 仪式感功能
- 创世开局演出（第一句输入作为「原初神谕」逐字浮现，世界卡逐张点亮）
- 每章生成史官笔法编年史段落；整档一键导出《创世史》（Markdown / EPUB）
- 神谱星图随剧情生长（关系变化时星轨亮起/断裂）

### 开发路线
- **M1 能玩**：世界生成 + 卡片编辑 + RP 对话 + 状态面板 + BYOK
- **M2 有深度**：章节结算 + 诸神回合 + 三层记忆 + 百科生长 + 迷雾
- **M3 完整**：陨落/余烬 + 时间线分叉 + 模板广场 + ST 导出 + 成书导出
- 交付方式：先方案文档（本文档集），确认后动代码
