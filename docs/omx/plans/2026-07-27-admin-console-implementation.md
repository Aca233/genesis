# 管理面板实施计划

## 阶段 1：契约与测试
1. 阅读 Next.js 16 项目内文档、better-auth 管理员插件及现有路由测试模式。
2. 为 requireAdmin、分页/搜索、错误脱敏和危险操作规则编写失败测试。
3. 为管理 DTO 的正文隔离与审计写失败测试。

## 阶段 2：数据库与服务层
1. Prisma 新增 AdminAuditLog 与 World.archivedAt，创建加法迁移并生成客户端。
2. 实现 admin 守卫、请求 IP、错误脱敏、分页解析和审计工具。
3. 实现总览、用户、世界、任务、LLM、审计查询服务，全部显式 select。
4. 实现用户、世界和任务管理动作以及事务审计。

## 阶段 3：路由与界面
1. 新增 /admin 布局与服务器端权限边界。
2. 新增总览及五个分区页面，复用现有星图、羊皮纸和鎏金设计语言。
3. 新增管理 API，逐端点调用 requireAdmin。
4. 实现手动刷新、筛选、分页、确认对话和操作反馈。
5. 移动端表格改为档案卡片。

## 阶段 4：验证与部署
1. 运行 Prisma 校验、目标单元/路由测试、集成测试。
2. 运行 TypeScript、ESLint、全量 Vitest 和生产构建。
3. 启动本地生产构建进行管理员/普通用户/移动端烟测。
4. 原子发布到生产，执行迁移、健康检查、权限检查与回滚点确认。

## 停止条件
只有设计验收项全部具备新鲜证据，且生产健康与权限烟测通过，才报告上线完成。
