# 05 · UI 设计

> 更新日期：2026-07-27

## 0. 连续世界 UI 增补

下文“五页签/本尊神格”仅适用于诸神共世。两种模式在正式游玩时共享同一输入组件：时之仪、一个 textarea、「续写」「发送」以及生成中的「搁笔」。Creator 不再显示观测/改写切换、scope 选择或独立敕令框；LLM 识别追溯既成历史后自动进入 rewrite SSE。

Creator 右缘符文为：**动态 / 星图 / 编年史 / 诸神录 / 天外视界 / 现实树 / 设定集 / 众生录**（另有香炉常驻，通往设置页），不显示「本尊神格」；万神殿符文为：**动态 / 星图 / 年表 / 往昔 / 神格 / 设定集 / 众生录**。符文图标不再是固定字符，而由各世界的图标主题解析（见 1.6）。天外视界展示当前分支、焦点、时间、全知/limited、活动化身和最近敕令；现实树是可键盘访问的层级树，支持进入、撤销、重命名、查看敕令和删除冻结子树。chat/settlement/rewrite 进行中禁用现实切换。

全知专属内容必须标记「天外批注 · 世界内不可见」：包括隐藏能力、未揭示栏目、议程和幕后编年史。limited 模式的秘密由服务端删除，不能依赖 CSS 隐藏。Creator 星图使用真实 God ID 的有向关系；非对称态度分别展示。

改写完成后全量刷新 state/实体索引并切换到新现实；timeline 变化时重置内部检查点/opening 引用。结果正文使用普通 Narrator 排版，只追加可打开现实树的轻提示「⌘ 现实已分叉」。

### 1.3 动效原则

**仪式浓、日常淡。**

- 仪式时刻（全力演出）：创世开局、陨落终章。
- 日常（克制）：文字流式浮现带轻淡入（无打字机音效感）、抽屉滑出带轻物理（spring 阻尼）、星图微呼吸、烫金微焕提示。
- 禁用：常驻粒子、视差、每次生成的光效。
- 日常过渡时长约定：悬停/按压 0.15–0.3s ease；主题与背景交叉淡化 0.6s ease；抽屉与任务条走 spring/`AnimatePresence` 轻物理。
- **减弱动效**（`prefers-reduced-motion: reduce`）：背景与主题交叉淡化、`gilt-pulse` 与 `animate-pulse`、玺印钮/卷轴拣选器/星标开关的过渡与按压位移一律取消；创世演出跳过逐字与拓印两幕，直接呈现世界题名（`useReducedMotion`）。减弱动效只省视觉，不改变任何流程。

### 1.4 浓墨古籍基础构件

各页面共用的「古籍构件」类定义于 `globals.css`，双主题取值全部经由 Token，禁止再手写同义的一次性样式：

| 类名 | 构件 | 要点 |
|---|---|---|
| `.tome-plate`（+ `.tome-plate--corners`） | 书卷面板 | 纤维纸底 + 外鎏金/内发丝双重描边 + 暖调投影，取代「1px 边框 + 圆角 + 单色填充」的通用卡片；`--corners` 追加四角双弦纹 + 四芒星纹饰，呼应背景星图蚀刻 |
| `.seal-button` | 玺印钮（典仪级 CTA） | 深墨底、金梯度描边、鎏金字、暖焕外光；悬停如余烬拨亮；禁用是「一枚未点燃的蜡印」——仍有体积，绝非幽灵轮廓 |
| `.illuminated-header`（+ `__glyph`） | 泥金章题 | 两侧发丝线向外淡出的节标题，可选引导纹章槽 |
| `.scroll-select` | 卷轴拣选器 | 去原生化 `<select>`：羊皮纸凹井、墨线描边、镌刻双弦纹箭头，聚焦鎏金 |
| `.star-toggle` | 星标开关 | checkbox 的四芒星化身：`<label class="star-toggle"><input type="checkbox"/>文案</label>`，勾选点燃鎏金星 |
| `.letterpress` | 铅印小签 | 0.3em 字距的中文 small-caps 质感标签 |
| `.display-md` / `.display-lg` | 宋体展示字 | 补齐巨题与小号表单字之间的中间字级（1.25rem/700、1.75rem/900） |
| `.stain-vignette` | 陈年晕渍 | 大面板的柔和旧边 |
| `.tome-scroll` | 古卷滚动条 | 细身鎏金游标浮于羊皮纸；文档级 `scrollbar-color` 已覆盖全站，此类用于局部滚动容器的显式声明 |

伪元素占位契约：`.tome-plate` 占用 `::before`（内衬细线）；`.tome-plate--corners` 与 `.stain-vignette` 均占用 `::after`——二者勿叠加于同一元素，需要时包一层。键盘焦点全站以未分层的 `:focus-visible` 烫金描边呈现，任何 `outline-none` 均不得压过它。

### 1.5 典仪层级：每页最亮之物

「创世 / 入界 / 发送」是三大典仪动作，各自页面上最亮的对象即玺印钮：

- 首页「创世」：`seal-button` 全尺寸主钮（进行态文案「凝聚世界中…」）；
- 往昔诸界「入界」（草稿为「续掷卡组」、已成史为「览史」）：玺印小钮；
- 游玩输入区「发送」：玺印小钮，置于深墨书案右缘。

次级典仪动作（导入存档、往昔页签「回到此刻」、设置页操作等）复用 `seal-button` 并以 `min-h-8! px-4!` 一类 important 工具类缩小尺寸；同一视口内不宜出现多枚全尺寸主钮。卡组编辑器页脚的「创　世」目前仍为鎏金描边钮（含「确认创世」二次确认），属浓墨古籍后续批次的收敛对象。危险/不可逆动作（书写陨灭终章、裁去、落刀）保持朱红系——不可逆之事不用最亮之物。

### 1.6 图标语言

图标分两层，均为 24×24 描线 SVG、`currentColor` 随墨色，无运行时网络请求，不引入 emoji。操作图集内联于客户端组件；世界图标主题层由服务端从预编译子集解析后内联下发：

- **操作图集 `OperationIcon`**：与世界无关的固定界面操作符，现有 `settings / close / check / add / archives / materials / censer / scroll / sun / candle / lock / dice / ascend` 十三枚，用于烛光切换、香炉（设置）、导航与卡片操作等；新增操作图标须进此集合。
- **世界图标主题 `WorldIconTheme`**：每个世界一份，创世时按题材生成——主家族默认 Phosphor，科技/赛博题材用 Tabler，东方/仙侠用 IconPark Outline；纹章家族固定 Game Icons（CC BY 3.0，随导出生成致谢清单）。主题内含导航符文（动态/星图/编年史/神格/天外视界/现实树/设定集/众生录八个角色）以及实体类型、能力、事件等语义 Token 的指派；玩家锁定的指派在主题重掷时保留。符文列与实体纹章均由此驱动。

## 3. 抽屉页签

页签构成随模式而异（完整符文列表见第 0 节）。下述 3.1–3.5 为核心面板；另有独立「动态」抽屉（06 篇 4 节）、万神殿「往昔」与 Creator「现实树」（06 篇 12 节）。

### 3.1 星图（神谱）

- **手绘天文图**风格：羊皮纸底、墨线星座、烫金星点、边缘古地图饰纹。
- 每神一星：大小=位阶，玩家神居中偏下（谦逊的视角）；连线=关系（盟友金实线/敌对朱虚线/竞争墨双线/未知无线）。
- 关系变化时星轨亮起/断裂（一次性动效）；未知关系不画线——星图本身即迷雾的呈现。
- 点击星 → 神明详情卡（人格/声纹/已知关系/已揭示议程片段；未揭示部分为残卷样式）。
- D3-force 布局 + 手动锚定玩家神位置；SVG 绘制。

### 3.2 编年史年表

- 竖排卷轴时间线：纪年（烫金）→ 章节 → 条目（史官笔法）。
- 只显示 `revealed` 条目；后揭示的条目带「于第 N 章揭晓」小注。
- 每章节点悬停出「自此分叉」入口（M3）。
- 顶部过滤器：按实体/神筛选（即实体专属编年史的全局入口）。

### 3.3 本尊神格

- 位阶（主题卡命名）、领域、信仰范围描述、化身状态、持有密约列表、神选者名册（跳转人物卡）。
- 位阶变化时此页签微焕。

### 3.4 世界设定集

- 分层文档树：宇宙论 / 力量体系 / 融合公理 / 历史纪元 / 世界书条目。
- 每节可展开阅读、可手改（player_locked）；随剧情自动增补的段落带淡金新墨标记。

### 3.5 众生百科

- 六类分栏（势力/人物/种族/地理志/圣物/教团），各栏列表卡片：纹章 + 名 + 一句话。
- dormant 实体折叠为摘要行；标星置顶；神选者带印记角标。
- 详情面板结构（通用）：
  - 头部：程序纹章（名字哈希→蜡封印章/墨线纹章 SVG；可上传图覆盖）+ 名号 + 别名
  - 栏目区：按类型模板（01 篇 9.1）；未揭示栏目→「传闻：……」或墨渍残缺样式
  - 底部：**专属编年史**（自动筛选的时间线——人物面板即她的一生）
  - 操作：标星 / 手改（朱批样式）
- 正文实体微光链接：悬停一句话快览（摘要），点击直达此面板。

## 4. 仪式演出

### 4.1 创世开局

1. 全屏纸底，玩家的原初神谕以文楷逐字浮现于页面中央（金色）。
2. 神谕沉入纸面，世界卡组逐张「拓印」浮现（宇宙论→神谱星点次第点亮→势力）。
3. 世界名、纪元、时间与「自此有史」晕开，卷入正文界面。
- 点击「创世」后物化与演出并行；物化完成立即生成 opening，动画结束时正文通常已接近完成。全程可跳过视觉，但仍等待 opening。

### 4.2 自动世界整理

1. 输入区锁定并显示「世界正在演化…」，正文保留在原位。
2. SSE 在后台推进诸神回合、抽取、编年史与快照，不显示章节或全屏翻页演出。
3. 完成后静默刷新时间、实体索引与编辑边界；失败时显示「世界整理中断」和「继续整理世界」。

### 4.3 陨落终章

- 纸面渐染墨色，终章文字以白金色浮现；结束后整卷合拢，显示「已成史」+《创世史》导出与「自历史分叉」入口。

## 5. 卡片编辑器（创世阶段）

- 网格卡片墙：每张卡=一页古籍笺（卡名+摘要），点开全文编辑。
- 卡片操作：重掷（骰形印章按钮，转动墨迹动效）/ 手改（朱批样式，改后字段上锁标记）/ 神谱卡内增删拖动。
- 议程卡默认背面朝上（「天机」封蜡样式），点击可翻开（自破迷雾警告一次）。
- 底部主按钮：「创世」。

## 6. 设置抽屉（香炉）

- 模型双槽位（叙事/幕后）：Base URL、Key（密文显示）、模型名、温度；「试炼一问」连接测试按钮。
- 可选 embedding 槽（折叠在「进阶」内）。
- 文风预设切换、AI 建议开关、烛光模式（手动/跟随时间）。
- 数据：导出/导入存档 JSON、导出《创世史》（MD/EPUB）、导出 ST 世界书。
