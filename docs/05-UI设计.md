# 05 · UI 设计

## 1. 视觉规范

### 1.1 主题：羊皮古卷

整体隐喻——**你在书写并阅读一部创世史书**。

| Token | 日卷模式 | 烛光模式 |
|---|---|---|
| 纸底 `--paper` | 暖米色 #F3EAD8 + 细纸纹理 | 深褐 #2B241C + 同纹理压暗 |
| 墨字 `--ink` | 深墨褐 #2E2418 | 暖白 #E8DFC8 |
| 烫金 `--gilt` | #A87F2E | #C9A356（微提亮） |
| 朱红 `--cinnabar`（朱批/警示） | #9E3B2C | #C05545 |
| 淡金辅助 `--gilt-soft`（建议/提示） | gilt @ 55% | 同 |
| 残卷雾 `--fog` | 墨渍灰褐 + 噪点 | 同压暗 |

- 双模式以 CSS 变量实现；烛光可手动切换或跟随系统时间（设置项）。
- 纸纹理用平铺 SVG 噪点+纤维纹，压极低对比度，不干扰阅读。

### 1.2 字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 正文叙事 | **霞鹜文楷**（LXGW WenKai） | 手写温度、古籍气质；self-host woff2 子集化 |
| 标题/章题 | **思源宋体** Heavy/Bold | 出版物感 |
| UI 辅助 | 系统黑体栈 | 设置、按钮、元信息 |
| 纪年/编号 | 思源宋体 + 烫金色 | |

### 1.3 动效原则

**仪式浓、日常淡。**

- 仪式时刻（全力演出）：创世开局、翻章岁月流转、陨落终章。
- 日常（克制）：文字流式浮现带轻淡入（无打字机音效感）、抽屉滑出带轻物理（spring 阻尼）、星图微呼吸、烫金微焕提示。
- 禁用：常驻粒子、视差、每次生成的光效。

- 正文中央限宽（约 34rem，65–75 全角字/行），两侧留白展示纸纹。

- 手机：符文列变底部栏，抽屉全屏化；不做独立移动交互设计（桌面优先，手机可用）。

### 2.2 消息交互（悬停手柄）

段落悬停浮现：**异文**（‹ 2/3 ›）· **朱批**（进入编辑态，朱红边）· **裁去**（裁至此处）· **续笔**（直接续/附导演提示）。已结算章节隐藏手柄（已成史，只读）。

## 3. 五页签抽屉

### 3.1 星图（神谱）

- **手绘天文图**风格：羊皮纸底、墨线星座、烫金星点、边缘古地图饰纹。
- 每神一星：大小=位阶，玩家神居中偏下（谦逊的视角）；连线=关系（盟友金实线/敌对朱虚线/竞争墨双线/未知无线）。
- 关系变化时星轨亮起/断裂（一次性动效）；未知关系不画线——星图本身即迷雾的呈现。
- 点击星 → 神明详情卡（人格/声纹/已知关系/已揭示议程片段；未揭示部分为残卷样式）。
- D3-force 布局 + 手动锚定玩家神位置；SVG 绘制。

### 3.2 编年史年表

- 竖排卷轴时间线：纪年（烫金）→ 章节 → 条目（史官笔法）。
- 只显示 `revealed` 条目；后揭示的条目带「于第 N 章揭晓」小注。
- 每章节点悬停出「自此分叉」入口（M3）。
- 顶部过滤器：按实体/神筛选（即实体专属编年史的全局入口）。

### 3.3 本尊神格

- 位阶（主题卡命名）、领域、信仰范围描述、化身状态、持有密约列表、神选者名册（跳转人物卡）。
- 位阶变化时此页签微焕。

### 3.4 世界设定集

- 分层文档树：宇宙论 / 力量体系 / 融合公理 / 历史纪元 / 世界书条目。
- 每节可展开阅读、可手改（player_locked）；随剧情自动增补的段落带淡金新墨标记。

### 3.5 众生百科

- 六类分栏（势力/人物/种族/地理志/圣物/教团），各栏列表卡片：纹章 + 名 + 一句话。
- dormant 实体折叠为摘要行；标星置顶；神选者带印记角标。
- 详情面板结构（通用）：
  - 头部：程序纹章（名字哈希→蜡封印章/墨线纹章 SVG；可上传图覆盖）+ 名号 + 别名
  - 栏目区：按类型模板（01 篇 9.1）；未揭示栏目→「传闻：……」或墨渍残缺样式
  - 底部：**专属编年史**（自动筛选的时间线——人物面板即她的一生）
  - 操作：标星 / 手改（朱批样式）
- 正文实体微光链接：悬停一句话快览（摘要），点击直达此面板。

## 4. 仪式演出

### 4.1 创世开局

1. 全屏纸底，玩家的原初神谕以文楷逐字浮现于页面中央（金色）。
2. 神谕沉入纸面，世界卡组逐张「拓印」浮现（宇宙论→神谱星点次第点亮→势力）。
3. 第一章标题晕开，卷入正文界面。
- 全程 15–25 秒，可点击跳过。

### 4.2 翻章 · 岁月流转

1. 屏幕暗角收拢，当前页面如书页翻动。
2. 期间滚动模糊低语碎片（「北境有神低语……」「星辰移位……」——由固定文案池+当前神名模板化生成，**不剧透**结算内容）。
3. 结算进度（SSE）驱动碎片节奏；完成后新章标题手写体晕开。
- 结算失败：演出退出，显示可重试的断点（结算状态机支持续跑）。

### 4.3 陨落终章

- 纸面渐染墨色，终章文字以白金色浮现；结束后整卷合拢，显示「已成史」+《创世史》导出与「自历史分叉」入口。

## 5. 卡片编辑器（创世阶段）

- 网格卡片墙：每张卡=一页古籍笺（卡名+摘要），点开全文编辑。
- 卡片操作：重掷（骰形印章按钮，转动墨迹动效）/ 手改（朱批样式，改后字段上锁标记）/ 神谱卡内增删拖动。
- 议程卡默认背面朝上（「天机」封蜡样式），点击可翻开（自破迷雾警告一次）。
- 底部主按钮：「创世」。

## 6. 设置抽屉（香炉）

- 模型双槽位（叙事/幕后）：Base URL、Key（密文显示）、模型名、温度；「试炼一问」连接测试按钮。
- 可选 embedding 槽（折叠在「进阶」内）。
- 文风预设切换、AI 建议开关、翻章建议开关、烛光模式（手动/跟随时间）。
- 数据：导出/导入存档 JSON、导出《创世史》（MD/EPUB）、导出 ST 世界书。
