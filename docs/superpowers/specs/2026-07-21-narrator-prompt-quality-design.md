# Narrator 叙事 Prompt 质量优化设计

## 目标

把已确认的“TGbreak 行为骨架 + Izumi 表现层”融入《创世》Narrator，同时保持《创世》现有时之仪、能力、卡片、编年史、结构化 META 和 Prompt Cache 架构。

## 范围

仅修改 Narrator Prompt 与对应测试、Prompt 文档。不新增模型调用，不输出或保存模型答案缓存，不修改数据库结构，也不把模型内部规划暴露给玩家。

## 稳定缓存边界

- `global`：玩家代理权、角色认知边界、角色塑造方法、文风原则、静默自检与 META 输出契约。
- `world`：世界卡、风格卡、主题卡、宇宙论、玩家神、诸神卡片。
- `dynamic`：时之仪尺度、征兆、查探、实体、能力、世界书命中、编年史、正文窗口与本轮神谕。

动态消息出现后不得再注入稳定消息。

## 行为规则

### 玩家代理权

玩家输入只授权其中明确写出的言语、行为与目标。Narrator 可以描写这些已授权行为的实施过程以及世界和 NPC 的反馈，但不得扩写成新的关键决定、额外对白、内心、情绪或信念。到达关键选择时在自然戏剧节点停笔，不输出“轮到你了”一类元叙事提示。

### 认知边界

每个 NPC 的言行必须能够追溯到其亲历、被告知、可靠推断或卡片明确提供的信息。Narrator 知道的隐藏信息不等于角色知道；作者侧能力只能影响能力拥有者的表现，不能借其他角色泄露机制。

### 活人感

角色反应由既有人格、当前目标、已知信息、关系、近期经历、能力与限制共同决定。允许产生意料之外但可回溯解释的反应，不随机添加永久人格标签，不让 NPC 自动围绕、认同或崇拜玩家神。

### 文风

采用正向写作目标而非机械禁词表：自然口语对白、动作呈现性格、常见景象白描、抽象感受才谨慎使用具体比喻、长短句随场景变化、避免解释性对白和模板转折。正文结尾停在动作、对白、景象或悬念上，不作主题总结或道德评价。

### 静默自检

模型在输出前静默检查代理权、认知来源、能力边界、因果连续、声纹与格式。不得输出思维链、草稿、检查表、规划标签或自我点评。

### 行动建议

META 中建议只描述玩家神可选择的行动或态度，不替玩家决定，也不预写行动结果。

## 验收

1. Global Prompt 明确包含上述六类规则。
2. 不改变 Narrator 消息缓存分层。
3. 不改变正文 + `<<<META` JSON + `META>>>` 的解析协议。
4. 不增加模型调用。
5. Narrator 目标测试、全量单元/集成测试、类型检查、Lint 和 Build 全部通过。
