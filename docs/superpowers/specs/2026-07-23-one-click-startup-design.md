# 一键启动脚本设计

## 目标

在项目根目录提供 `启动.bat`，让 Windows 用户双击后即可完成本地开发环境的必要检查、数据库启动、数据库迁移和 Next.js 开发服务器启动，并自动打开浏览器。

## 启动流程

1. 将工作目录切换到脚本所在的项目根目录，确保脚本可从任意位置启动。
2. 依次检查 `node`、`pnpm` 和 `docker` 命令；任一命令缺失时显示明确提示并保留窗口。
3. 若 `.env` 不存在，则从 `.env.example` 复制生成；若模板也不存在则终止。
4. 若 `node_modules` 不存在，则执行 `pnpm install`；安装失败时终止。
5. 执行 `docker compose up -d` 启动 PostgreSQL；失败时提示用户确认 Docker Desktop 已运行。
6. 执行 `pnpm prisma migrate dev` 应用开发数据库迁移；失败时终止，避免在数据库状态未知时继续启动应用。
7. 在后台延迟打开 `http://localhost:3000`，为开发服务器预留启动时间。
8. 在当前窗口执行 `pnpm dev`，以便用户持续查看日志并可用 `Ctrl+C` 停止服务。

## 错误处理

- 每个关键命令执行后检查退出码。
- 失败时输出当前失败阶段及建议操作。
- 失败或开发服务器退出后执行 `pause`，防止双击运行时窗口立即关闭。
- 脚本不自动覆盖已有 `.env`，也不自动写入密钥。

## 验证

- 静态检查 BAT 的标签、条件分支、引号和退出码处理。
- 通过 `cmd /c` 运行脚本的安全检查路径，确认命令解析正常。
- 不在验证期间长期占用开发服务器；实际启动行为仍由用户双击脚本触发。
