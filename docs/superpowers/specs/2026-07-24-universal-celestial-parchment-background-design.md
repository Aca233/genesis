# 通用星图古卷双主题背景设计

## 目标

为《创世》的主游玩界面补充一组通用背景，在不依赖具体世界题材的前提下增强“阅读并书写创世史书”的氛围。背景必须服务于长文本阅读，不能与正文、右缘符文列和底部输入区争夺注意力。

## 视觉方向

采用“星图古卷”方向：

- 抽象宇宙星图、古地图墨线、同心轨道、少量创世符印与克制的边角纹饰；
- 不出现人物、动物、建筑、武器、具体地貌或可识别文明；
- 不出现文字、字母、数字、徽标、水印或伪文字；
- 图像应像一张平铺在视野中的古老宇宙图谱，而不是带桌面、书本边缘或透视角度的场景插画。

## 双主题

交付两张构图一致的 16:9 背景：

1. **日卷母版**
   - 暖米色旧羊皮纸；
   - 淡褐与烟灰色墨线；
   - 低饱和古金点缀；
   - 整体明亮、温润、干净，不发黄过度，不呈脏污或焦黑。

2. **烛光版**
   - 以日卷母版作为参考图编辑；
   - 严格保留星图、轨道、符印、边饰的位置、比例和轮廓；
   - 将纸张转换为深褐黑古卷，将墨线转换为更暗的层次，将金色星点微微提亮；
   - 保持克制，不做高对比发光、霓虹或大片纯黑。

## 构图与阅读安全区

- 原始尺寸：`3840 × 2160`；
- 中央横向约 58%、纵向约 86% 为正文阅读安全区；
- 安全区内只保留极淡、低频、低对比纸纹，不放置星点、圆环交点、符印、边框、地图轮廓或强污渍；
- 主要装饰集中在左右各约 21% 的侧翼和四角；
- 装饰可以在两侧形成视觉平衡，但不要精确镜像，以免产生廉价图案感；
- 四周必须自然延伸到画布边缘，不出现硬边框、相框、书页边缘或暗角黑框；
- 背景需允许 CSS `cover` 裁切：左右和上下边缘的装饰被少量裁去后，画面仍然成立。

## 生成流程

1. 使用 `gpt-image-2` 生成日卷母版，质量选择 `high`，尺寸选择 `3840×2160`，输出 PNG。
2. 检查日卷母版的阅读安全区、题材通用性、边缘延展性和文字伪影。
3. 将合格的日卷母版作为参考图交给 `gpt-image-2` 编辑为烛光版。
4. 烛光编辑只改变颜色、明度、材质气氛和金墨亮度，不重构任何图形。
5. 两张图返回后进行本地后处理：
   - 对齐和尺寸校验；
   - 清理伪文字与局部高对比瑕疵；
   - 必要时对中央区域做低频降噪和对比度压制；
   - 导出适合网页使用的优化版本，同时保留原始 PNG 母版。

## 验收标准

- 在当前主游玩页的正文后方不降低中文长文可读性；
- 日卷和烛光切换时，所有图形位置保持一致，没有明显跳动；
- 缩放到常见桌面宽屏后，左右两侧仍有可见装饰，中央不出现视觉焦点；
- 图中没有可读文字、伪文字、水印、人物、建筑或特定题材物件；
- 日卷版不显脏，烛光版不糊成纯黑；
- 背景独立观看有质感，叠加现有 UI 后退居第二视觉层级。

## 暂不包含

- 根据每个世界动态生成专属背景；
- 移动端专用竖版背景；
- 动态粒子、视差或常驻发光动画；
- 首页、创世仪式、抽屉面板等其他页面的独立插画。
