# 06 · 前端设计

> 更新日期：2026-07-27

## 1. 连续世界界面

游戏内没有玩家可见章节。`Chapter` 只作为后端检查点，正文区连续展平最近记录，不显示章号、章题、章节边界或“结束本章”按钮。

页面标题固定为：

```text
世界名 · 纪元 · 时间
```

纪元来自 `RealityState.currentEra`，时间来自 `ObserverState.timeLabel`。时之仪位于输入区，负责选择下一轮默认时间跨度。

两种模式共用：

- 一个正文流；
- 一个 textarea；
- 时之仪；
- “续写 / 发送 / 搁笔”；
- 真实任务状态条。

Creator 不再显示“观测/改写”切换，意图统一交给 Narrator。

## 2. 开局正文

点击创世后，世界物化、就绪动画与 opening 生成并行：

1. 原初神谕沉入纸面；
2. 世界卡与符文逐步点亮；
3. opening 在后台立即开始流式生成；
4. 动画结束时，正文应已部分或大部分可读；
5. 跳过动画只跳过视觉，不启动第二份 opening。

Opening 与普通正文共用幂等 generation 机制，刷新或断线后恢复同一任务。

## 3. 真实任务状态条

状态条贴近输入区，不覆盖已有正文。三类任务均由真实后端阶段驱动：

### 正文

```text
接收请求 → 组装上下文 → 生成正文
→ 校验并保存模型输出 → 写入正文与状态 → 更新世界动态
```

### 世界整理

```text
读取检查点 → 推演诸神行动 → 抽取持久变化
→ 更新编年史 → 生成内部快照 → 完成
```

### 现实分叉

```text
理解追溯意图 → 建立计划 → 克隆现实
→ 应用新历史 → 生成结果正文 → 整理并切换
```

视觉状态：

- pending：灰色空心；
- running：烫金高亮；
- completed：淡金勾；
- failed：朱红并停在具体步骤。

可恢复失败显示“从此处重试”；世界已变化等不可恢复错误只显示“刷新世界”。完整正文已生成但尚未应用时，预览继续可读并标“尚未写入世界”，输入暂时锁定。禁止用笼统“读取中”遮挡正文。

## 4. 独立「动态」抽屉

右缘符文新增独立“动态”入口；移动端进入底部栏。面板分三段：

1. **当前关注**：标题、阶段、摘要、最近进展、参与者、可见性与取消关注；
2. **重要事件**：未解决优先，按最近更新排列；当前关注置顶；展开后按时间展示进展链；
3. **近期动态**：按时间倒序分页，展示纪元、时间、类型、正文和相关对象。

动态中的神、人物、势力、地点等可跳转对应详情抽屉。打开面板不触发聊天、不推进时间、不调用 LLM。

## 5. 关注交互

- 一次只能关注一个重要事件；
- 无关注时，事件卡显示“追踪”；
- 已有关注时追踪另一项，前端先确认“替换当前关注”；
- 当前事件显示“取消追踪”；
- 请求成功后只更新本地活动视图与观察状态；
- 关注不会立即生成正文或切换当前场景。

事件解决后，服务端清空关注；前端刷新时移除当前关注卡。

## 6. 未读状态

- 动态符文显示本地未读数量；
- 重要事件进入新阶段时短暂烫金；
- 关注事件出现进展时显示更醒目的圆点；
- 打开动态抽屉后，把当前最新活动游标记为已读。

未读游标是纯 UI 状态，不写入 LLM 上下文，不改变 `public / player_known / hidden`。

## 7. 可见性呈现

| 模式 | public | player_known | hidden |
|---|---|---|---|
| Pantheon | 正常显示 | 正常显示 | 不下发浏览器 |
| Creator limited | 正常显示 | 正常显示 | 不下发浏览器 |
| Creator omniscient | “世人皆知” | “局部知晓” | “天外批注 · 世界内尚未知晓” |

hidden 必须由服务端过滤，前端不能靠折叠或 CSS 保密。Creator 看见幕后内容不会改变 NPC 认知。

## 8. 自动世界整理

整理时正文保留原位，输入区锁定并显示当前真实步骤；不出现翻页、章末对话或“结束本章”仪式。完成后静默刷新：

- 纪元和时间；
- 正文编辑边界；
- 实体索引；
- 动态、事件与关注状态。

失败时保留正文和已完成步骤，显示“继续整理世界”。

## 9. Phase 4 前端接入

Phase 4 不新增主循环入口，只扩展现有动态面板：

- 展示整理合并后的单一动态；
- 支持普通动态升级为重要事件后的来源链接；
- 已解决事件折叠到历史区；
- 派生事件显示父子关系；
- 现实切换后重新读取新 Timeline 的动态和关注 ID；
- v4 存档导入后按新 ID 恢复事件链，未读游标按本地规则重新计算。

## 10. 浓墨古籍基础构件接入

`src/app/globals.css` 是古籍构件的唯一定义处（构件清单与设计意图见 05 篇 1.4）；页面一律以类名组合复用，不复制样式：

- 颜色 Token 经 Tailwind v4 `@theme inline` 映射为 `text-gilt-bright`、`bg-seal-ground-lo`、`border-line` 等工具类；暖调投影用 `shadow-tome` 工具类，免去任意值书写。
- `.seal-button` 缩小尺寸用 important 工具类覆盖（如 `min-h-8! px-4! py-1! text-xs`），不新造按钮类。
- 伪元素契约：`.tome-plate` 占 `::before`，`.tome-plate--corners` 与 `.stain-vignette` 均占 `::after`——同一元素勿叠加，需要时包一层。
- `:focus-visible` 烫金描边定义在任何 `@layer` 之外，恒压过工具类 `outline-none`；新组件不得自造焦点样式。
- 减弱动效分两层实现：CSS `@media (prefers-reduced-motion: reduce)` 关停背景/主题过渡、`gilt-pulse`/`animate-pulse` 与玺印钮、卷轴拣选器、星标开关的过渡位移；创世演出用 `motion/react` 的 `useReducedMotion` 跳过逐字与拓印两幕，直接呈现世界题名。

## 11. 图标体系

图标不经运行时网络请求：构建期本地打包、服务端解析、内联 SVG 下发。

1. **目录**（`src/lib/icons/catalog.ts`）：语义 Token（如 `cosmos.constellation`、`entity.faction`）映射到各家族图标 id 与许可证；家族为 Phosphor / Tabler / IconPark Outline / Game Icons 四套 `@iconify-json` 本地集合。
2. **世界主题**（`theme.ts`）：`parseWorldIconTheme` 对任意输入自修复为合法主题；`buildWorldIconTheme` 按卡组题材选主家族（科技→Tabler、东方→IconPark、默认 Phosphor），纹章家族固定 Game Icons；玩家锁定指派经 `mergeLockedIconAssignments` 在主题重掷时保留。
3. **解析**（`resolver.ts`）：`resolveIcon` 优先级为玩家覆盖 → 世界锁定指派 → 类别指派 → 目录回退；`matchIconConcept` 把 LLM 给出的概念词映射到 Token，无匹配时按世界与主体 id 哈希做确定性兜底。
4. **渲染**：`loadLocalIcon`（server-only）把图标 id 转成内联 `SvgIconData`；客户端 `WorldIcon` 渲染内联 SVG（无 `label` 时 `aria-hidden`）；符文列 `RuneRail` 接收每世界导航图标，缺失时用内置回退圆环。与世界无关的固定操作用 `OperationIcon` 集合（05 篇 1.6）。
5. **致谢**：Game Icons 为 CC BY 3.0；`collectIconCredits` 汇总世界实际用到的图标，`renderIconCreditsMarkdown` 生成致谢清单随导出物分发。

## 12. 终局与游玩新组件

### 12.1 FinaleGate（陨灭终章确认流）

- `status=concluded`：输入区整体替换为只读横条「此界已成史。万象俱在，唯不可再书。」+ 返回往昔诸界链接；抽屉面板全部保留（览史模式）。
- `status=playing` 且玩家神位阶跌至陨灭：输入区上方出现「神焰已熄」面板——「于余烬中挣扎」写入 `sessionStorage`，本次会话不再打扰；「书写陨灭终章」需二次确认（朱红警示「终章一经写下，此界永为史册」→「落笔」），成功后进入已成史态。
- 终章按钮走朱红系而非玺印钮：不可逆动作不用最亮之物。

### 12.2 万神殿「往昔」页签（PantheonPastPanel）

- 检查点列表：每条为纤维纸卡（「时间 · 第 N 卷」+ 摘录）；可回溯项配玺印小钮「回到此刻」，旧存档快照标注「不支持回溯」。
- 回溯确认为卡内墨批行（原位替代 `window.confirm`）：朱红文案说明「将从那一刻分出新的现实，当前历史冻结保留」→「确认 / 且慢」。
- 确认后 POST `/realities`（`action: "fork"`，携带 `expectedActiveId` 与 `idempotencyKey`），成功即切换到新时间线；面板下半部内嵌 `RealityTreePanel`（`mode="pantheon"`），供玩家在自己的诸多分叉间穿行。
- chat/settlement/rewrite 进行中回溯禁用（与现实切换同一规则）。

### 12.3 分歧对照（RealityDiffView）

- 入口在现实树：任一节点点「对照」选定一界，再于另一界点「与之对照」；只读，不受 busy 限制。
- 数据来自 GET `/realities/compare?left=&right=`：标题显示分歧时刻；共同历史折叠为一行计数（「共同历史 · N 条已折叠」）；编年史差异按左右两栏卡片排布，`rewrite` 来源带「敕令」徽章、未揭示条目带「暗记」徽章。
- 众生分歧逐实体成卡：仅存于一侧者朱红标注；摘要与栏目差异左右对读，缺失栏目显示「—（无此栏目）」。
- 两界完全一致时显示残卷雾文案「两界尚未分道扬镳」。

### 12.4 本轮变化折叠行（MessageBlock）

Narrator 正文尾部的折叠行「◈ 本轮变化 · N 项」，把 finalize 落库时写入 `meta` 的世界变化推到玩家眼前：

- 神谕结果（如愿 / 部分如愿 / 受挫 / 反噬——受挫与反噬朱红）；
- 时间推进（纪元·时间）；
- 世界行动与动态条目——`visibility === "hidden"` 一律不渲染，防泄露幕后行动；
- 能力显露与结算缘由徽章（重大事件、位阶变动、纪元更替等中文措辞）。

流式生成中不显示；变化数为零时整行不出现。

### 12.5 神权提示条（InputDeck）

- 仅万神殿模式、输入框聚焦且空闲时，于输入区上方列出玩家神的神赋能力小签（封印/失落/废弃不列；creator 传空数组即隐藏）。
- 点击仅把能力名插入输入文本（句读收尾时直接续接，否则自动补逗号），**不是发动按钮**；效果与代价放在 `title` 悬停提示里。
- 与 AI 建议条并存：建议条高度恒定、以透明度淡入淡出，神权条随聚焦出现；两者都不得顶起书案。
