# 01 · 产品设计

> 更新日期：2026-07-27。除明确标注「设计中」「M3」「预留」的条目外，本篇机制均已实装。本次更新并入第二波游戏性交付（陨灭终章、检查点回溯重玩、现实分歧对照、将临之事、诸神主动登台、神谕结果申报、神权提示条、回访钩子、纪元总纲等），相应小节标注「已实现」；世界导演内核（world-director，时间一致世界生成设计稿 §14）仍为设计稿，文中相关机制均为其接手前的过渡实现。

## 0. 双模式玩家旅程（权威增补）

首屏先选择「诸神共世」或「创世主」，再输入原初描述。模式不可变。下文所有“玩家神、本尊神格、纯角色内扮演”仅适用于诸神共世。

### 诸神共世

保留原有流程：生成玩家神卡和玩家神，围绕该神进行神谕、化身、迷雾、关系和余烬玩法。

### 创世主

- 卡组没有玩家神区域；主神关系引用世界内神明稳定 ref。
- 开局是当前纪元的世界全景，不出现玩家降临、受封、信仰或隐藏身份。
- 正式游玩只有一个输入框，不再让玩家选择「观测」或「改写现实」；观察、行动、确立未来事实和追溯请求统一交给 Narrator LLM 理解。
- 观察、行动和面向未来的改变继续写入当前现实；只有推翻既成历史的 `retroactive` 意图才自动建立现实子分支并确定性应用白名单计划。
- 追溯分叉保留旧消息作为旧现实证据；现实树支持查看敕令、进入、撤销父现实、重命名和删除冻结子树。
- 全知/limited 只改变服务端投影，不修改数据库中的 `revealed` 或能力可见性。
- 可创建人物化身，进入后世界角色只感知化身；退出/收回不删除历史引用，化身生死不削弱绝对改写权。

世界不会因 Creator 存在而停止自主运转；诸神回合、抽取、编年史与征兆由自动世界整理执行。世界操作租约确保叙事、整理、改写、现实切换互斥。

### 非目标

不支持模式转换、现实合并、平行现实同时推进、多人权限或对敕令设置资源/成功率门槛。


本篇是玩法系统的全量规格。所有设计均源自头脑风暴锁定的决策，不引入未确认的新机制。

## 1. 玩家旅程总览

```
首屏输入一句话
   ↓
创世生成（世界卡组）
   ↓
卡片编辑（任意重掷/手改）
   ↓
创世开局演出
   ↓
┌────────── 游玩循环 ──────────┐
│  自由 RP（场景/年代/纪元变焦） │
│  ⇄ 查探迷雾 / 神神互动        │
│  ⇄ 自动世界整理               │
│     （诸神回合+抽取+压缩）     │
└──────────────────────────────┘
   ↓（可选终局）
陨落 → 史诗终章 → 检查点回溯分叉重开
随时：导出/导入存档（《创世史》导出、发布模板：设计中）
```

## 1.1 世界模式：创建时一次选择

创世首页首先展示两个同等入口：

- **诸神共世**：原有神格 RP。卡组包含唯一玩家神；开局后模式固定为 `pantheon`。
- **创世主**：绝对作者视角。卡组与运行态都不得出现 `playerGod`、`isPlayer`、`tier: player`、`stanceToPlayer` 或对玩家关系；开局后模式固定为 `creator`。

选择是世界身份不变量，不提供转换、复制为另一模式或隐藏玩家神的兼容路径。存档卡与游玩页始终显示模式徽章。

## 2. 创世流程

### 2.1 首屏

- 一个居中的输入框（古卷样式），提示语类似「说出你的第一句神谕——你是谁，这是怎样的世界」。
- 无示例库、无提示词条（已决策：保持纯净）。
- 可选入口：「从模板开始」（M3 模板广场）、「导入存档」。

### 2.2 生成产物：世界卡组

玩家输入一句话（如「战锤40K+凡人修仙传融合，我是飞升失败坠入亚空间的道尊」）后，系统一次性生成以下卡组：

| 卡片 | 内容 | 数量 |
|---|---|---|
| **宇宙论卡** | 世界起源、力量体系、天道/物理法则、神之存在方式（信仰依赖？位格来源？） | 1 |
| **融合公理卡** | 仅多 IP 融合时产出：两套体系如何缝合、力量对标表、冲突时以谁为准 | 0–1 |
| **神谱卡** | 每位主神一张：名号、领域、位阶、人格、声纹、议程（隐藏）、与玩家神的初始关系 | 6–9 |
| **次要神列表** | 一句话设定的小神集合，可升格 | 不限 |
| **玩家神卡** | 出身（AI 推断：新神/既有神/转生神/篡位者）、领域、位阶、初始信仰势力、开局处境、3–6 项神权 | 1 |
| **势力卡** | 主要国家/宗门/教团/军团，含信仰归属 | 3–6 |
| **种族卡** | 主要种族；每种族 2–5 项先天能力/族群技艺 | 按需 |
| **主要人物卡** | 姓名、身份、主种族、势力职务、目标、2–5 项个人技能、已掌握技艺与先天例外 | 6–12 |
| **地理卡** | 主要大陆/圣地/都城 | 按需 |
| **纪元冲突卡** | 当前时代的主要矛盾与暗流（部分对玩家隐藏，作为诸神议程的种子） | 1 |
| **将临之事** | 作者侧未来候选事件：标题、时间标签、全局先后序、前置/阻断条件、预期后果——对玩家隐藏，卡组界面不展示（见 5.3） | 3–5（可选） |
| **叙事风格卡** | 从输入推断的文风预设 + 变焦文体规则 | 1 |
| **主题卡（UI）** | 界面措辞微调用（如纪年名称、称谓习惯） | 1 |

生成规则要点：

- 原 IP 有神系则**用回原神系**（40K 四邪神+帝皇；无职转生人神/奥尔斯蒂德等），模型知识不足处以导入的 ST 世界书为准。
- 神系庞大时自动主次筛选：与玩家神戏剧张力最强的 6–9 位入主神席，其余入次要神列表。
- 玩家神与每位主神各有 3–6 项神权；玩家神的神权全部可见，主神至少一项已知，可保留与具体秘密、暗流或议程相关的传闻/隐藏神权。
- 每个种族仅生成 `racial_innate`（先天能力）或 `racial_tradition`（族群技艺）：前者由该种族人物默认继承，后者必须明确学习，不会因种族归属自动掌握。
- 6–12 位主要人物是统一名录；势力关键人物、人物主种族、势力成员关系和能力来源都用稳定 `ref` 连接，不以显示名称充当关系主键。
- 每位主神的**议程卡在卡组界面默认隐藏**（这是迷雾的一部分），但玩家可选择翻开（自破迷雾，自由是玩家的）。

### 2.3 卡片编辑

- 每张卡可**单独重掷**（保持其他卡不变，重掷时将其他卡作为约束传入）。
- 每张卡可**逐字段手改**；手改字段打上 `player_locked` 标记，后续重掷与自动更新不得覆盖。
- 神谱卡可增删主神、次要神与主神互相拖动升降格。
- 种族卡可编辑能力的效果、触发、代价、限制、掌握、状态与可见性；主要人物卡可编辑主种族、势力职务、明确掌握的族群技艺、先天覆写和个人技能。删除或改动被引用条目时必须同步修复引用。
- 满意后点击「创世」，系统在同一事务中物化种族/势力/人物、人物种族与成员关系、种族能力、神权、人物个人技能、技艺掌握和先天覆写；任一步失败整体回滚。

### 2.4 世界书导入

- 卡组界面提供「携带典籍」入口：上传 SillyTavern worldbook JSON（支持 v2 格式 entries 结构）。
- 导入条目作为**检索语料**参与世界生成与后续叙事（关键词触发机制原生对齐 ST）。
- 生成器在创世时会优先与世界书条目对齐设定，冲突时以世界书为准（玩家显式提供的资料 > 模型内部知识）。

## 3. 叙事系统

### 3.1 尺度三档（显式切换器）

| 档位 | 镜头 | 文体 | 典型输入 |
|---|---|---|---|
| **场景** | 具体时刻、逐句对话与动作 | 小说正文 | 「我垂听那个祭司的祈祷，在他梦中显现」 |
| **年代** | 数年–数十年蒙太奇 | 编年纪事与特写交替 | 「接下来三十年，我让教团向北方蛮族传教」 |
| **纪元** | 百年以上、文明兴衰 | 史官笔法宏观叙事 | 「此后三百年，我沉睡，只留一缕神念看护圣地」 |

- 切换器为输入区上缘三枚书签丝带，当前档垂下；切换后输入框占位文字随之变化。
- 时之仪决定默认跨度；玩家当前输入中的明确时间文字优先于表盘且只作用于这一轮，服务端不反向改动表盘。
- AI 输出文体严格跟随本轮有效跨度，不要求玩家确认，也不在回复末尾提醒切档。
- **化身入世**：场景档下玩家可宣告化身为凡人入世，此后以凡人视角 RP，神格面板显示化身状态；化身死亡不伤本尊（按世界观设定裁决）。

### 3.2 消息四件套（古卷化）

| 功能 | 命名 | 交互 |
|---|---|---|
| 同轮多候选 | **异文** | 段落右上角「异文 2/3」，左右切换，选定即定稿；未定稿前其余候选保留 |
| 编辑任意消息 | **朱批** | 点开消息进入编辑态，边缘泛朱红；AI 输出与玩家输入皆可批 |
| 回溯删除 | **裁去** | 选定某条消息，裁去它及其后所有消息，回到该状态重推 |
| 续写/导演提示 | **续笔** | 让 AI 接着写；或附一句幕后指示（「接下来让使者带来坏消息」）后再续 |

- 裁去、朱批和异文只在**当前开放检查点**内自由使用；此前正文显示为「已成史」，服务端拒绝直接修改。推翻既成历史需由创世主输入触发现实分叉。

### 3.3 AI 行动建议

- 每段 AI 叙事的**同一次生成**中附带 2–4 条行动建议（结构化输出的一个字段，不额外调用）。
- 呈现为输入框上方的淡金小字悬浮，点击填入输入框可改再发。
- 设置中可全局关闭。

### 3.4 结构化能力与叙事裁决

四类能力共享同一套叙事字段，但语义不同：

| 类型 | 拥有者与获得方式 | 对局语义 |
|---|---|---|
| **先天能力** `racial_innate` | 种族模板；人物随主种族默认继承 | 人物可有强化、变异、受损、封印或失去等来源覆写 |
| **族群技艺** `racial_tradition` | 种族模板；人物必须明确掌握 | 不因种族归属自动获得；创世引用或后续正文习得才生效 |
| **个人技能** `personal` | 主要人物及剧情晋升的重要人物 | 仪式、政治、知识、工艺、统御、调查等均可，不等同于战斗招式 |
| **神权** `divine` | 玩家神与主神 | 玩家神查看自己的全部神权；其他神明仍受迷雾投影 |

每项能力记录效果、触发、代价、限制、掌握程度、当前状态、可见性与可选来源。叙事裁决综合这些边界、对手能力、神力位阶、世界法则、时之仪尺度和已建立事实；能力不是必胜按钮，也不得在正文中临时扩张边界。

本系统**不提供技能快捷按钮或点击发动交互**，也**不引入法力值、伤害、冷却、命中率、成功率等数值战斗**。玩家仍以自然语言行动，系统只把结构化能力作为叙事真相和裁决依据。

**神权提示条（已实现）**：诸神共世模式下，输入框聚焦时上方浮现玩家神当前神赋能力的提示条（封印/失落/废弃项不列），逐项展示名称、效果与代价；点击仅把能力名插入输入文本，供玩家自行组织语言——它是备忘而非发动按钮，与上述无按钮原则一致。创世主模式无此条。

### 3.5 神谕结果申报（已实现）

- 每轮叙事的同一次 META 中，Narrator 可对本轮玩家神权行使/神谕自报一个裁定结果：`fulfilled / partial / thwarted / backfired`，附一句因由。
- 消息下方「本轮变化」折叠列表以「神谕如愿 / 部分如愿 / 受挫 / 反噬」呈现，受挫与反噬以朱砂色警示。
- 这只是叙事裁决的结果登记，不引入成功率或任何数值判定。

## 4. 诸神系统

### 4.1 主神的三张卡

每位主神由三部分构成：

1. **人格卡**（玩家可见）：名号、领域、位阶、性情、外显形象、已知关系。
2. **声纹卡**（玩家可见）：语癖、称呼习惯、口头禅、绝不会说的话。神议会群戏时逐神注入，防止众神一个腔调。
3. **议程卡**（默认隐藏）：当前目标（长期/短期）、手段偏好、对玩家神的真实态度值（敌意/竞争/中立/合作/依附五档 + 一句话动机）、进行中的密谋列表。
4. **神权谱**：玩家神的全部神权向本人公开；主神只公开 `known` 项，`rumored` 仅给模糊传闻，`hidden` 项不下发名称、ID、效果、触发、代价或限制。

### 4.2 诸神回合（自动世界整理）

每次世界整理，幕后模型为**每位主神**执行一次议程回合：

```
输入：该神议程卡 + 本章大事记 + 与其相关的百科条目 + 融合公理卡
输出（结构化）：
  - action: 本章节该神采取的 1 个幕后行动（描述）
  - omen: 该行动在世间可感知的征兆（一句，将织入下章叙事）
  - agenda_update: 议程/态度的增量更新
  - relations_update: 与其他神/势力关系的增量更新
  - proactive_event?: 行动直指玩家神时必填（类型 + 开场钩子），入独立登台通道（4.4）
```

规则：

- 行动写入**隐藏大事记**（`revealed=false`），玩家不可见。
- **征兆（omen）**交给叙事模型，在下一章的叙事中以「润物细无声」方式织入——不打标记、不进面板，就是正文里一句寻常的「今夜北境的祭火比往常暗了一分」。
- 神与神之间的密约、玩家与某神达成的盟约，都会写入双方议程卡——**盟友会真的帮你，背叛者会真的坑你**。
- 次要神不跑回合；被剧情升格为主神后开始跑。

### 4.3 迷雾与揭示

- 迷雾同时覆盖诸神议程、隐藏编年史、百科栏目与能力。能力采用 `known / rumored / hidden`：已知项展示完整机制；传闻项只展示名称和 `rumorText` 等安全摘要；隐藏项由服务端直接过滤，不能依靠前端折叠或 CSS 隐藏。
- 玩家通过**角色内手段**主动查探：占卜、洞察、审问使者、派神选者调查、化身潜入……
- 叙事模型在处理查探行动时，检索隐藏大事记中相关条目，按玩家手段的合理性裁决揭示程度（可部分揭示、可获得误导性线索——按叙事逻辑走）。
- 查探裁决的注入有两道门（已实现）：本轮输入命中查探语义（占卜、洞察、审问、追查等），或上一轮叙事在 META 中自报「本轮已发生查探」——查探未了结时跨轮延续裁决，不因玩家换了措辞而中断。
- 一旦揭示：隐藏编年史补录进玩家可见年表（标注「于第 N 章揭晓」），相关百科栏目点亮；能力则依证据从 `hidden → rumored` 或 `hidden|rumored → known`，并写入一条 `revealed` 沿革。
- 百科条目同理是**栏目级迷雾**：未知栏目显示「传闻：……」或经卷残缺样式。

### 4.4 诸神主动事件（已实现）

诸神回合的行动若直指玩家神（托梦、遣使、神迹挑衅、议会传召），该神必须同时给出**主动事件**（类型 + 开场钩子），经独立登台通道（征兆队列 `kind=proactive`）送入后续叙事——世界会来找玩家，而不只是等玩家推动。

- 每轮叙事至多租借 1 条主动事件 + 2 条普通征兆；主动事件必须**正面登台**：点名神明、当轮演出，不得降格为一句暗示。
- 两阶段消费：叙事成功落库后才标记事件已消耗，中途失败不丢失。

## 5. 连续世界与内部检查点

### 5.1 自动世界整理

- 玩家看不到章节号、章题、翻章提示或「结束本章」按钮。数据库中的 `Chapter` 只作为内部检查点窗口。
- 每轮 Narrator 在同一响应中返回正文、时间补丁和安全轻变化；观察焦点、在场状态、活动化身及有限实体栏目等白名单变化立即原子落库。
- 以下任一情况自动触发世界整理：累计六个 Narrator 回复、纪元改变、宽尺度且实际推进时间、能力/死亡/势力/位阶/身份/关系等重大变化。
- 整理流水线（顺序执行，幕后模型承担）：
  1. **诸神回合**（4.2）
  2. **状态与能力抽取**：从当前检查点正文抽取有明确证据的持久变化
  3. **编年史压缩**：正文 → 2–3 句带纪年的史官条目 + 一段小结
  4. **热度衰减**：沉寂实体降档为摘要卡
- 第二波结算增强（已实现）：**时间预算**——只在既有纪年标签体系内裁决时间推进，禁止自造历法（导演内核接手前的过渡投入）；**神权代价审计**（仅诸神共世）——对玩家神本窗口行使的每项神权裁定「践约/回避」，被回避的代价化作暗记进入征兆队列，日后在世间显形。将临之事状态维护见 5.3，纪元总纲见 5.4，神选者寿数与成长里程碑见 §6。
- 整理期间输入完全锁定并显示「世界正在演化…」；失败时已生成正文不丢失，刷新可恢复，玩家也可点「继续整理世界」。
- 每条能力变化必须指向具体消息并引用连续正文证据；幂等键保证断点续跑不重复演化。
- 整理完成自动落内部快照并开启新的无标题检查点，正文视觉上保持连续。

### 5.2 开放窗口与已成史

- 当前开放窗口：消息四件套可用，安全轻变化已即时入卡。
- 此前窗口：正文只读成史；编年史、百科为准。页面连续展示最近四个内部窗口，最多 80 条消息，不渲染内部边界。

### 5.3 将临之事：条件式未来正史（已实现）

- 创世卡组可选生成 3–5 条**将临之事**（CanonFutureEvent）：作者侧的未来候选事件，含标题、展示用时间标签、全局先后序、前置条件、阻断条件与预期后果；开局时物化入库，状态 `pending`，对玩家完全隐藏（`author_only`）。所有引用一律使用卡组稳定 ref，不落库 DB id，因而可被现实克隆零重映射携带。
- 世界整理是唯一的状态裁决者，状态机只进不退：`pending → eligible / altered / cancelled / occurred`；`eligible → occurred / altered / cancelled`。
- 待发条目（pending/eligible）注入结算提示词作为**压力而非剧本**：标题、概要与条件不得逐字出现在任何玩家可见文本中，也不得无剧情因由地把诸神回合、抽取或编年史往它们身上引；叙事模型完全看不到任何 canon 字段。
- 判定 `eligible` 时可附一条**传闻**半透出：以凡人可感知的走样低语落成一条公开动态（稳定 ID 幂等）——真相的影子，而非日程表。
- `altered / cancelled` 只在作者侧留下改道说明（divergenceNote），不产传闻；`occurred` 记录成真的检查点序号，事件经正文与结算动态机制自然成真，不自动生成追踪事件（导演内核接手前的边界）。
- 检查点回溯分叉时，将临之事状态随快照复归到该时刻（旧快照缺此字段则保持原状）。

### 5.4 纪元总纲与编年史检索（已实现）

- 纪元在某个检查点内落幕时，结算把该纪元的编年史条目蒸馏成一条 150–400 字的**纪元总纲**（史官笔法，只写世界公开可知之事），以 `era_digest` 入库，幂等不重写。
- 叙事上下文中纪元总纲**常驻注入**（至多 20 条），不随近期条目滚动淘汰——远古纪元不再被遗忘。
- 其余编年史注入改为**实体名索引检索**：命中本轮相关实体的条目优先，近期条目兜底。

### 5.5 回访钩子（已实现）

- **存档状态行**：往昔诸界列表为每个进行中世界附一行「你离开时」状态——当前纪元与时间、追踪中的公开事件标题、未读动态数（与入界页阅读游标对比）。纯派生自既有数据，不做任何 LLM 调用。
- **离席之间**：现实时间离席 ≥ 12 小时后再入，下一轮叙事注入重入导演块——以世界自身的运动开场，幕后线索（诸神共世用租借征兆、创世主用活跃事件标题）在无人注视时已悄然推进；绝不解释或提及停顿本身。

## 6. 神选者系统

- 玩家以角色内行动「赐下印记」将凡人入册为神选者（叙事模型识别此类行动并在抽取时标记）。
- 神选者待遇：
  - 独立人物卡**永不被热度降档**、永不被记忆压缩磨掉；
  - 追踪**寿数**（凡人会老死——面板上看着她从少女变成老妪是核心戏剧装置）与**信仰历程**（何时入信、动摇记录）;
  - 可作为凡间代理人博弈的棋子（玩家指派任务，其他神也可能腐化/策反她——经由诸神回合）。
- 寿数与成长（已实现）：每次世界整理对全部在册神选者的寿数**逐一表态**（更新/不变/大限将近/寿终），凡人会真的老死；能力臻于化境时自动记一笔**成长里程碑**——一条公开动态加一条编年史条目，断点重跑不重复。
- 不限量，由叙事自然决定规模。

## 7. 陨落与低谷

### 7.1 位阶谱系（轻状态，无数值）

`陨灭 — 余烬 — 沉睡 — 微末 — 成神 — 显赫 — 主宰`

（生成时按世界观重命名，如修仙世界可作「兵解—残魂—蛰伏—散仙—真仙—大罗—道祖」——主题卡负责措辞。）

- 位阶升降由叙事模型在重大事件后裁决、章末抽取时落卡，不做数值运算。

### 7.2 余烬视角（已实现）

- 跌至「余烬」：叙事切换为低谷文体——神力媒介近乎断绝，玩家只能通过残存的一点媒介行动（最后一个信徒的梦、一件圣物的微光、半被遗忘的祷词）；全幅神迹、直接显圣与诸神级发声不可用，强行为之必在台上失败或落空。
- 行动建议与文体全面收窄：只给间接、小尺度的手段，营造「以萤火撬动世界」的绝地感；复燃的微光经凡人信仰若隐若现，但绝不白给。东山再起后正常恢复。
- 跌至「陨灭」：在余烬文体之上再加临终笔调——每一个残存动作都可能是最后一个。

### 7.3 陨灭终章（已实现）

- 玩家神跌至「陨灭」后，输入区上方浮现终章确认面板：可选「于余烬中挣扎」暂不成史（本次会话不再打扰），或确认就此收束。仅诸神共世模式可用。
- 确认后由幕后模型一次性生成**史诗终章**：史官笔法收束整条时间线——神焰如何熄灭、世界记住与记错了什么、幸存诸神与神选者的去向、身后长影；同时落 1–3 条编年史条目。无 META、无行动建议——终章之后此界只读。
- 终章写入与世界状态切换在同一事务内完成：世界进入「已成史」（concluded），当前检查点结算封卷；生成失败时世界保持可玩、可重试。
- 已成史后：输入区替换为只读横条「此界已成史。万象俱在，唯不可再书」，往昔诸界列表落朱砂「已成史」封蜡；现实树一并冻结，任何改动返回 409。正文、编年史与百科仍可随时回望。
- 导出《创世史》（Markdown/EPUB）仍在设计中。

### 7.4 检查点回溯：分叉重玩（已实现）

- 诸神共世新增「往昔」页签：列出当前现实所有已结算检查点（时间标签 + 卷号 + 摘录），并内嵌现实树（以「往昔诸相」措辞呈现同一棵树）。
- 任一携带 v2 快照的检查点可「回到此刻」：二次确认后复用创世主分叉机制克隆整条时间线，截断该时刻之后的历史，并按快照还原众神、众生、能力、事件、征兆、将临之事与时间态——从那一刻分出新现实，原历史冻结保留，可经现实树随时回望或撤回。
- 快照升级前结算所留的旧版快照不可回溯（页签内明示「旧存档快照，不支持回溯」），只能回望。

## 8. 创世主观察、绝对改写与现实树

### 8.1 统一输入

- 创世主与诸神共世共享时之仪、单输入框、「续写」「发送」「搁笔」。
- 创世主输入以 `【创世主意图】` 注入，Narrator 自行识别观察、行动、确立未来事实或追溯既往；UI 不展示 scope 选择。
- 只有追溯既成历史时输出 `retroactive_rewrite` 并分叉；其他输入都作为普通连续推进，不创建现实分支。

### 8.2 追溯分叉

- `retroactive`（追溯）：重构既成事实；旧消息原文作为前一现实证据保留并标记，不原地篡改。
- 追溯任务仍只允许白名单补丁，引用必须属于源现实或同计划新建对象；完成后自动触发新现实的世界整理。

### 8.3 自动分支与撤销

每次追溯以活动现实为源，完整克隆内部检查点、消息、神、实体、栏目、能力、能力事件、成员关系、编年史和征兆，重映射所有内部 ID 后确定性应用计划，最后以 CAS 切换到新子现实。旧现实冻结保留，绝不继续推进。

现实树支持：进入任意现实、撤销到当前父现实、重命名分支、查看敕令和删除非根且非活动的冻结子树。切换/撤销不会合并状态；从旧节点再次改写会形成兄弟分支。明确不做并行模拟、分支合并、多人协作或模式转换。

**现实分歧对照（已实现）**：任意父子或同父兄弟两界可发起只读对照——编年史逐条对齐分歧，众生实体按摘要与栏目双栏并列，仅存在于一侧的实体单独列出。诸神共世观者视角下自动过滤暗记与未揭示栏目。已成史（concluded）的世界整棵现实树冻结，一切改动请求返回 409。

### 8.4 观察视角与化身

Creator 默认 `omniscient`，服务端下发完整议程、隐藏能力、未揭示栏目和幕后编年史，同时保留它们在世界内的可见性标记，以「天外批注」区分。切换 `limited` 后复用玩家安全投影，秘密字段不下发，不通过前端遮盖。

Creator 可聚焦世界、地点、实体、神或化身；可创建人物型化身，选择种族与最多 12 项能力，并进入、退出或收回。收回只令化身休眠并保留历史；化身死亡或休眠不改变 Creator 身份、全知能力或改写权限。

## 9. 世界百科（Codex）

### 9.1 六类实体面板模板

| 类型 | 专属栏目（除通用的概览/关系/专属编年史外） |
|---|---|
| **势力** | 疆域、政体、都城、人口级别、**信仰栏**（信奉哪些神及浓度：狂信/普遍/暗中/敌视）、关键人物（跳转）、军力（可迷雾） |
| **人物** | 身份、所属（跳转）、主种族、**年龄与寿数**、性格与声纹、**信仰历程**、有效能力与沿革、与玩家神关系（信徒/神选者/仇敌/浑然不知）、神选者印记 |
| **种族** | 特质、寿命、分布、与诸神的渊源、种内势力（跳转）、先天能力与族群技艺 |
| **地理志** | 类型（大陆/城市/秘境/圣地）、归属（跳转）、地貌与气象、发生过的大事 |
| **圣物·力量体系** | 类型（神器/功法/科技/体系概念）、持有者（跳转）、能力、来历、当前下落（可迷雾） |
| **教团** | 信奉之神（跳转）、教义、圣地（跳转）、组织结构、异端派系、与世俗势力关系 |

### 9.2 通用机制

- **概览**：一段史官笔法介绍 + 程序化徽记（名字哈希→蜡封印章/墨线纹章；可上传图覆盖；预留 `image_url` 字段接二期 AI 生图）。
- **专属编年史**：面板底部，从全局编年史按实体自动筛选——人物面板即她的一生，势力面板即它的兴衰史。
- **栏目级迷雾**：每栏有 `revealed` 状态；未揭示呈「传闻：……」或残卷样式。
- **生长**：每轮安全轻变化即时入卡，自动世界整理负责复杂建卡/增补；玩家手改字段 `player_locked`，自动更新不得覆盖。
- **热度分层**：`active`（全卡）/`dormant`（摘要卡，面板折叠成简介）；近期出场、玩家标星、神选者保持 active；dormant 实体再次出场自动复活全卡。
- **正文联动**：已入册实体名在叙事正文自动渲染为微光链接（烫金微焕），悬停显示一句话快览，点击开面板。

## 10. 旧世界与存档兼容

- 结构化能力上线前创建的旧世界保持原状：不迁移、不回填、不提供一键补全，也不会凭空生成 6–12 位主要人物。
- 旧世界可以继续游玩；只有后续剧情明确展示某项能力，并在章末抽取中提供正文证据时，才为相关人物或神明渐进建档。
- 私有存档导出不按可见性裁剪；`version: 4` 完整保留世界模式、现实树拓扑、改写记录、观察状态、Creator 化身、隐藏能力、来源引用、人物种族/势力关系、能力沿革，以及将临之事与征兆通道类型。导入后所有语义 ID 和树引用均重映射并重新验证。
- 导入仅接受 `version: 4`，必须通过唯一根、无环、同世界父子、活动节点、改写来源/结果一致及模式不变量校验；旧版本存档不再兼容。

## 11. 设置（香炉抽屉）

- **双模型槽位**：叙事模型 / 幕后模型，各含 Base URL、API Key、模型名、温度等参数；内置连接测试。
- **文风**：当前风格卡查看/切换预设。
- **开关**：AI 行动建议、烛光模式（手动/跟随时间）。
- **数据**：导出存档 JSON / 导入存档；导出《创世史》（Markdown/EPUB）与导出 ST 世界书（设计中）。

## 12. 内容边界

- 平台不加内容限制层；尺度完全取决于玩家自选模型与其 Key 的服务条款（BYOK 责任归属）。
- 模板广场（M3、小圈子阶段）仅做发布者自评标签，不建审核体系；若未来公开运营再启用预留的审核钩子。

## 万象藏库：创世素材复用

- 世界成功开局后，最终编辑卡组自动拆成独立素材：宇宙论、融合公理、时代冲突、文风、主题、神明、种族、势力、地点、主要人物及每项能力。
- 素材默认全部收录；玩家可收藏、隐藏和搜索。收藏项优先展示，隐藏项仍完整保留且仅作为幕后约束。
- 创世时逐张选择具体版本，并选择“融合改写”“原样继承（核心锁定）”或“完全锁定”；人物、能力等依赖逐项决定带入、重建或省略。
- 能力既随所属对象保存，也能独立复用。独立能力可指定已选合法拥有者，或允许创世引擎分配/创建类型合法的拥有者。
- 每张素材首次收录产生不可变初始版；剧情中的对象可手动保存后续版本。历史版本不可覆盖，只能复制或追加新版本。
- 删除来源世界不会删除素材与版本；已经启动的创世任务使用冻结快照，不受素材后续修改或删除影响。
- 所有素材约束合并进既有的一次流式创世请求，不按素材额外调用模型；首轮约束失败只使用原有的一次结构修补。
